# 音效生成（模块八 · `sfx`）设计文档

## 1. 目标

用火山引擎豆包语音的生成式音频模型 **`seed-audio-1.0`**，在插件里直接做游戏音效：

- 一句话描述 → 音效 / 环境音 / UI 声 / 生物吼叫 / 角色配音；
- 可选 1 张参考图（图生音）或最多 3 条参考音频（风格 / 音色参考），两者互斥；
- 每次生成一条 take，永不覆盖；可试听、单条导出、全部打 zip；
- 单次输出上限 120 秒；每次生成真实计费，失败不自动重试。

## 2. 非目标（v1）

- 不做本地剪辑（裁剪 / 增益 / 淡入淡出 / loudnorm / 波形编辑）；
- 不做批量 `n`、自动重试、自动重生成；
- 不接 Ark 生图 Key、谱乐 AI Key 或自定义音频后端；
- 不暴露 `speaker` 音色 ID、`enable_subtitle` 字幕时间戳、`pcm` 原始输出；
- 不在界面上开新对话；音效是直接生成，工具面另走 `game_material_*`。

## 3. API 映射

| 请求字段 | 来源 |
|---|---|
| `model` | 配置 `sfxModel`，默认 `seed-audio-1.0`（短名） |
| `text_prompt` | 任务提示词（≤2048） |
| `audio_config.format` | `mp3 / wav / ogg_opus` |
| `audio_config.sample_rate` | 8000 / 16000 / 24000 / 32000 / 44100 / 48000 |
| `audio_config.speech_rate` | -50~100 |
| `audio_config.loudness_rate` | -50~100 |
| `audio_config.pitch_rate` | -12~12 |
| `references` | 参考图 `image_data` 或参考音频 `audio_data`（互斥） |
| `watermark.aigc_watermark` | 开关，默认关 |

- 端点：`POST {sfxBaseUrl}/api/v3/tts/create`，默认 `https://openspeech.bytedance.com`。
- Header：`Content-Type` / `X-Api-Key` / `X-Api-Request-Id`；**不发** `X-Api-Resource-Id`。
- 返回：`audio`（base64）或 `url`（2 小时临时地址）；`duration` 与 `original_duration`。
- 鉴权用**语音控制台 API Key**，不是火山方舟的 `ARK_API_KEY`。

## 4. 数据模型

```text
<DSH_HOME>/game-material-master/sfx-jobs/<f…>/
├── job.json
├── refs/
├── takes/
└── out/
```

`SfxJob`：

- `id` / `name` / `createdAt` / `updatedAt`；
- `prompt` / `settings` / `reviewMode`；
- `refs.image?` / `refs.audios[]`；
- `status`: idle / running / ready / error；`error?`；
- `takes[]`: id / file / bytes / format / duration / originalDuration / prompt / settings / createdAt / logId；
- `stages.generate` / `stages.export`（status + approved）；
- `exports[]`；`log[]`。

所有写 `job.json` 走 `patchSfxJob()` 的按任务串行队列（`writeJsonAtomic`）。

## 5. 状态机

```text
idle → running → ready（新增 take）
              ↘ error（不新增 take）
```

- 并发闸门：同任务已有任务在跑时返回 `started:false`。
- 取消：abort 本地请求；远端可能仍完成并计费。
- 重启：`activateSfx()` 复位任务表；`resumeSfxJobs()` 把残留 `running` 标失败。

## 6. 参考素材

- 图片：PNG / JPEG / WebP，≤10MB；`sniffImage` 校验。
- 音频：WAV / MP3 / OGG(Opus)，≤10MB，尽量用 `probeAudio` 量时长并拒绝 >30 秒；缺 ffprobe 时不阻塞。
- 图与音频互斥；音频最多 3 条，顺序即 `@音频1…@音频3`。
- 参考文件进 `refs/`，通过资源路由可预览。

## 7. 界面

- 模块页签「音效生成」；左侧任务列表 + 新建音效；右侧详情。
- 新建对话框：名字 / 提示词 / 格式 / 采样率 / 审核模式；创建不调用模型。
- 详情：提示词与参数、参考上传与删除、生成按钮（计费提示）、takes 列表、导出、通过、日志。
- 生成中 `BusyBtn` + `LoadingOverlay`；轮询每 2.5 秒。
- 草稿合并：提示词/参数只有「草稿 === 上次宿主值」才跟随轮询更新，切任务 `force`。
- 所有文案 `T()`，英文词条同步；格式名由客户端翻译，不用宿主中文 label。

## 8. 工具面

- `game_material({action:'intake', {module:'sfx'})`：问提示词 / 参考 / 审核模式；缺 Key 进 blockers。
- `createSfxJob` → 可选 `game_material({action:'upload', {kind:'referenceImage'|'referenceAudio'})`
  → `runSfxGeneration`（★计费）→ `game_material({action:'wait'})` → `game_material({action:'review'})` → `exportSfx`。
- `status` 列表带 `sfxJobs`；`review` 返回 takes / stages / nextActions；`approve` 支持 `generate|export`。
- 模块可被功能管理隐藏；隐藏后工具面全部拒绝。

## 9. 失败模式

| 场景 | 行为 |
|---|---|
| Key 未配 / 填了 Ark Key | 前置 blocker；401/403 明确说 Key 来源 |
| 模型未开通 | 10074 / resource not granted → 提示去语音控制台开通 |
| 429 / 超时 | 任务 error；不自动重试，重试前问用户 |
| 返回空 / 非音频 | 丢弃，不落盘；任务 error |
| URL 下载失败 | 任务 error；URL 只有 2 小时 |
| 参考混用 / 超数量 / 超大小 / 超时长 | 提交前或上传时拒绝 |
| 并发提交 | 闸门返回 `started:false` |
| 生成中删除 | 拒绝 |
| 宿主重启 | 残留 running 标失败（可能已计费） |
| 轮询覆盖草稿 | `mergeDrafts()` 保护 |
| 隐藏模块 | UI 与工具面同时拒绝 |
