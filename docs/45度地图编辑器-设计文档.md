# 45° 地图编辑器（模块五 · iso）· 设计文档

> 给维护者看的。面向用户的功能介绍在 [README.md](../README.md)；
> 实现细节与踩坑在 [ENGINEERING.md](ENGINEERING.md) 的「模块五」。

## 一、它是什么

一个**全本地、零计费**的 2:1 等距地图编辑器：导入自己的菱形素材（或使用内置素材），
在 45° 俯视网格上画地面、放多格物件、放标记，导出 PNG / JSON / 素材包 / zip。

它取代了原来那个「AI 生成 45° 地块」的模块五（`tile`）。原模块的 AI 生成、模板、
规整、拼图全部删除；保留的是它的研究结论：**2:1 正交等距是唯一可靠的几何口径**。
模块六「地图编辑器」（正方格俯视）保持原样，两者数据与渲染完全独立。

## 二、几何

| 项 | 口径 |
|---|---|
| 单元格 | `cell.width × cell.height`，默认 `64×96` |
| 菱形 | 宽 = `cell.width`，高 = `cell.width / 2`（严格 2:1） |
| 步进 | `stepX = cell.width / 2`，`stepY = cell.width / 4` |
| 菱形位置 | 在单元格里居中（中心 `cell.width/2, cell.height/2`） |
| 世界原点 | 格子 (0,0) 的菱形中心；计划 x/y 可以为负 |
| 命中 | 反解实数 r/c 后 `floor(v + 0.5)`；环绕时取模 |
| 物件锚点 | 图片底边中点 = 占格菱形的中心 |

`stepY` 来自**菱形高**的一半，不是 `cellHeight / 4`。写成后者会得到 24（正确 16），
整张图会裂开，而且不报错。

## 三、数据模型

```ts
IsoProject { id, name, cell, wrap, tilesets[], stages, logs, reviewMode? }
IsoDoc {
  id, name, cols, rows,
  layers: [{ id, name, kind: "ground" | "object" }],
  data: Record<layerId, number[]>,      // 地面层语义序号；物件层全 0
  objects: [{ id, tilesetId, layerId, r, c }],
  markers: [{ id, r, c, name }]
}
IsoTileset {
  id, name, file, imageWidth, imageHeight, cell,
  kind: "ground" | "autotile" | "object",
  columns, frames, variants, animRows,
  footprint?, anchor?, objectScale?, pass?, loop?, fps?, clarity?, builtin?,
  tiles: MapTile[]
}
```

- 地面层 `data` 存的是**全局图块序号**（1-based，0 = 空）。
- 物件是**独立源数据**，不写进 `data`：一格只装得下一个序号，装不下「占 2×2 + 通行性」。
- 自动连接是 4×4 = 16 块，行优先 `mask = 0..15`，位序 `N=1 / E=2 / S=4 / W=8`。
- 物件不跨环绕接缝（占格必须完整落地）；地面 / 标记 / 自动连接邻居全部取模。

## 四、渲染

宿主算**绘制计划**：每条 op = `{l, r, c, t, x, y, a, z, cycle?, fps?}`。
客户端只 `drawImage`，并把所有可见 op **按 `z` 排序**；导出 PNG 执行同一份计划、同一个顺序。

`z = layerIndex * 1e12 + depth * 1e6 + r * 4096 + c`；物件 depth 取「最靠前的占格」。
所以地面层永远先铺，物件层按前后遮挡；同一格内不会出现「预览好看、导出位移」。

计划缓存按 8×8 格的 chunk 增量下发：界面报 `have`，宿主只回缺的块；
编辑后用 `dropKeys` 精确失效。环绕视口可以出现负 chunk key。

## 五、素材

- **地面**：网格图块；静态时每块一个笔刷，`animRows` 时每列一个笔刷、每行一帧。
- **自动连接**：严格 4×4 = 16 块，缺 mask 时回退最近的接法并告警，绝不留空洞。
- **物件**：一张完整图（可多帧竖排），按底面中心摆放；可高出单元格（树冠 / 屋顶）；
  `footprint` 只决定占格与遮挡；`pass[]` 逐格通行性（0 / 1 / 2）。
- **物件大小 `objectScale`**（0.1~4，1 = 图片宽度正好占满 `footprint`）：导入时烘进
  `tilesets/` 的存图（`footprint.cols × cell.width × objectScale`），渲染 / 导出都不再读它。
  「新增素材」里用滑杆实时预览，用户自己决定图片相对地格多大；越界明确报错，不静默夹住。
- 属性在导入时定死；之后只能改名字 / 播放速度 / 循环方式（`saveIsoTileset`）。
- 内置素材由 `src/isosamplegen.ts` 程序化生成，确定性、零外部请求。

### AI 生成素材

素材卡里点「AI 生成素材」不会在插件里生图，而是开一个**不挂靠项目的新对话**，把目标项目、格子、
素材名、帧数、生成方式、用途（自动 / 地面 / 物件）和物件占格写进首条消息。对话里的 agent
用图片 / 序列帧模块生成，然后调用 `composeIsoAsset` 整理到 `ai/`，再把回链贴回来。

- 首版只支持 **ground**（单块 2:1 菱形；多帧竖排成动画地面）与 **object**（整张图 + footprint）。
  **autotile 4×4 不在首版**，仍走手工导入。
- `composeIsoAsset` 负责抠绿、按 alpha 裁内容、地面缩进菱形框（边缘向平均色收敛以减少重复铺的缝）、
  物件按 footprint 缩放；最多保留 4 倍分辨率，回链带 `scale` 供「新增素材」预填。
- 回链参数：`dialog=add&asset=ai/<名字>.png&shape=ground|object&frames=…&scale=…&cols=…&rows=…&keyed=1`。
- 只整理、不自动导入；用户在「新增素材」点「确定」后才进入素材列表。

## 六、导出

`dsh-gem-iso-map@1`：

```jsonc
{
  "format": "dsh-gem-iso-map@1",
  "projection": "isometric-2:1",
  "cell": { "width": 64, "height": 96 },
  "grid": { "stepX": 32, "stepY": 16, "wrap": true },
  "cols": 32, "rows": 32,
  "tilesets": [{ "id", "name", "image", "kind", "cell", "frames", "footprint" }],
  "legend": [{ "index", "tilesetId", "kind", "rect" }],
  "layers": [{ "id", "name", "kind" }],
  "ground": [{ "layerId", "data": [] }],
  "objects": [{ "id", "layerId", "tilesetId", "r", "c" }],
  "markers": [{ "n", "name", "r", "c" }],
  "pass": [{ "r", "c", "kind" }]
}
```

产物：`map.png`、`map.json`、可选 `tilesets/**`、多产物时 `<地图名>.zip`、`manifest.json`。
每次导出先清空导出目录；zip 时间戳写死，同文档两次导出逐字节一致。

## 七、界面

- 一屏：顶栏项目菜单 / 素材 / 导出 / 图层 / 设置；左列调色板 + 12 个图标工具；右侧 canvas。
- 工具：撤销、重做、画笔、橡皮、油漆桶、吸管、抓手、标记、图层、网格线、一键生成、设置。
- 图层卡：地面层 / 物件层可改名、换序、增删、清空、单层预览；标记层固定一行。
- 素材卡：列表、新增、恢复默认、素材说明；点一行改名字 / 速度 / 循环。
- 「新增素材」预览按**地图像素**画真正的 2:1 菱形地格（一个 SVG `viewBox` 等比缩放到对话框），
  物件底面的落地点画成黄点；物件大小滑杆**就放在预览图正下方**（边调边看），拖动图片可改锚点。
- 导出卡：PNG / JSON / 素材原图三复选框 + 唯一「导出」按钮；本机绝对路径、下载、打开目录。
- 全部文案走 `T()`，中英各一份。

| `verify-iso-gateway.mjs` | 21 个方法 / schema 逐键 / AI 回链 `shape=ground|object` |
| `verify-iso-client.mjs` | 客户端坐标函数与宿主逐点黄金对照、按 z 绘制、pending/have、界面结构、方法表、AI 对话框与回链 |
